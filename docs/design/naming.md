# Mosaicast naming and brand usage

Working name selected by the user on 14 October 2026.

- Product name: **Mosaicast**.
- Stylized wordmark: **MosAIcast**, with subtle AI emphasis.
- Tagline: **Your music. Your art. Your room.**
- Ukrainian tagline: **Твоя музика. Твої зображення. Твоя кімната.**
- Meaning: mosaic + AI + cast; music, artwork, devices, and rooms coming together.
- Use Mosaicast in ordinary interface text, documentation, speech, and accessibility labels; reserve MosAIcast for visual branding.
- English (`en`) and Ukrainian (`uk`) must have equal functionality and complete interface coverage.
- Proposed mobile identifier: `mosaicast`. The existing Home Entertainment repository and current branch retain their names.

## Initial name research

This is a development identity. Trademark, domain, app-store, and package-name availability have not been established.

An unrelated Laravel event package already uses [Mosaicast](https://packagist.org/packages/artisan-toolbox/mosaicast). Initial searches did not identify an obvious same-name music controller, but do not establish legal clearance. Styling the name MosAIcast does not eliminate naming conflicts.

The shorter Mosaic/MosAIc overlaps with [dCS Mosaic](https://dcsaudio.com/mosaic), an existing music-control product. MusAIc overlaps with music projects including [musaic](https://github.com/al165/musaic) and [Musaic](https://musaic.ltd/).

Mosaicast replaces the earlier Sonductor proposal in the design brief. Music control is the foundation; room artwork and optional agent coordination extend it.
