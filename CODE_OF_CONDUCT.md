# Community code of conduct

Treat contributors with respect. Welcome people of every background, language,
identity, and experience level. Discuss code and evidence; accept corrections.

Harassment, threats, discriminatory abuse, sexualized comments, doxxing, and
publishing private information are not acceptable in issues, pull requests,
discussions, or other project spaces.

Maintainers may remove content or restrict participation and will apply these
rules consistently. Reports can be sent through a private GitHub reporting
channel when available. Otherwise ask a maintainer publicly for a private
channel without posting personal details. Maintainers must keep reports private
except where disclosure is needed to address an incident.
